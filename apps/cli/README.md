# srgical

Srgical is a browser-first local workspace for AI-assisted software work.

```bash
npm install -g @launch11/srgical
srgical [working-directory]
```

The executable starts the local backend and opens Studio. Choose a repository or plain folder, start a conversation, and select any model reported as available by the authenticated Codex or Claude provider. Planning, worktrees, merge-conflict actions, skills, hooks, and connectors live in the browser UI; there is no separate terminal workflow.

See the [repository README](https://github.com/LaunchEleven/Srgical#readme) for the full product overview.
